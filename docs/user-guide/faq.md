# FAQ

Version: 0.1.0-SNAPSHOT

Last updated: 2025-11-08

---

Q: Where are converted files stored?

A: Converted files go to the configured **Output folder**. Change it in **Settings**.

Q: Can I cancel a running conversion?

A: Yes. Click **Cancel** for the batch or for individual files.

Q: Will the app overwrite my original files?

A: Not by default. Enable **Delete original after success** or confirm overwrite prompts.

Q: Can I run conversions on a headless server?

A: No. This is a GUI desktop app. Use native CLI tools for headless workflows.

Q: How do I report a bug?

A: Use **Help → View Logs**. Attach logs, a small sample file and steps to reproduce.
