# Best practices

Version: 0.1.0-SNAPSHOT

Last updated: 2025-11-08

---

- Test each preset with one file before running a large batch.
- Use descriptive output folder names per project.
- Keep backups of originals until verification completes.
- Reduce concurrency if the system shows high I/O or memory pressure.
- Use **Audio copy** when you do not need to re-encode audio.
