# Basic usage

Version: 0.1.0-SNAPSHOT

Last updated: 2025-11-08

---

This page describes common tasks and the main workflow.

Add files

1. Click **Add Files** or drag files into the main window.
2. Use **Add Folder** to add a folder recursively.
3. Select rows to edit per-file settings.

[Screenshot: Main window with file list and toolbar]

Choose output format and preset

1. In the **Output Format** column choose the target format.
2. Pick a global preset from the **Preset** drop-down.
3. Edit per-file overrides in the file details pane.

Start a conversion

1. Confirm the **Output folder** in **Settings** or the toolbar.
2. Click **Start** to begin the batch conversion.
3. Use **Pause** or **Cancel** while the job runs.

Monitor progress and view results

- The **Progress** column shows percent complete per file.
- The **Status** column shows Pending, Running, Completed, Failed, Cancelled.
- Select a completed row and click **Open Output Folder** to reveal the file.

[Screenshot: Progress view and per-file logs]

Quick tips

- Test presets on a single file before batching.
- Use **Open with default app** to preview outputs.
